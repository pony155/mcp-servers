# Aseprite RPG Icon Set Production

Obtain the icon size, safe area, background treatment, state variants, naming convention, and engine export contract first. Define a shared palette and lighting direction, then prioritize recognition at native scale: one dominant silhouette, one focal material cue, and controlled contrast against the actual UI background.

Keep each icon in a stable frame, layer, or slice scheme chosen for the export pipeline. Reuse structural motifs without making categories indistinguishable. Preview contact sheets frequently to catch scale, padding, and contrast drift across the set. Before release, validate pixel-art constraints, required slices or tags, duplicate names, palette limits, and atlas output.
