# Aseprite Cutscene Animation Production

Start from the approved shot list, resolution, playback clock, dialogue timing, and engine event schema. Separate reusable character motion, background plates, overlays, and camera-relative elements into stable layers. Use tags for shots or beats and events for dialogue, sound, cuts, and gameplay handoff.

Retime against the target duration without moving approved key poses unless requested. Use motion reports to catch unintended jumps and bake directional playback when the runtime cannot interpret tag directions. Review contact sheets for staging, animated previews for cadence, and event metadata after every structural frame edit. Export deterministic frame and layer names with the final timing manifest.
