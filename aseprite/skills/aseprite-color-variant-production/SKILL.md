# Aseprite Color Variant Production

Analyze source color usage and assign semantic roles before replacement. Keep invariant colors separate from variant ramps and preserve relative value contrast across skin, clothing, equipment, outline, and effects.

Create every variant as a new document using exact replacement or a reviewed palette. Preview representative frames and the darkest/lightest contexts, compare structure with the source, and report the mapping, final palette size, and any lost distinctions.
