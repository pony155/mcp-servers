# Aseprite Nine Slice Ui Production

Confirm native scale, fixed border thickness, minimum target size, center tiling or stretching behavior, and state variants. Define slice bounds and center in local coordinates; keep decorative features out of stretched regions unless their distortion is intentional.

Preview every asset at the minimum, representative, and maximum target sizes. Check corners, one-pixel borders, repeated patterns, content padding, and state contrast, then extract or atlas the source with pivots and slice metadata intact.
