# Aseprite Directional Animation

Define direction names, clockwise ordering, camera angle, shared baseline, frame count, and whether left/right directions may be mirrored. Identify asymmetrical clothing, weapons, handedness, lighting, and readable features that prohibit automatic mirroring.

Complete and validate cardinal directions before diagonals. Compare matching phases across directions for volume, foot contact, displacement, and timing. Use explicit tags and pivots, then validate the full set and document mirrored frames, intentional directional differences, and export ordering.
